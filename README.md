# Chethan Gowda — Website Development Portfolio

A responsive static portfolio built with semantic HTML, organized CSS, and vanilla JavaScript.

## Files
- `index.html` — page content, project previews, contact details, and project brief form.
- `style.css` — design tokens, layout, responsive breakpoints, and accessible motion settings.
- `script.js` — mobile navigation, scroll progress, reveal animations, and WhatsApp form handling.

## Run locally
1. Extract the ZIP archive.
2. Open the folder in VS Code.
3. Start the Live Server extension, or open `index.html` in a modern browser.

## Contact form
The project brief form opens WhatsApp with the visitor's name, project type, and project description prefilled. It does not store or submit information to a backend.

## Project previews
The two project previews attempt to load the actual websites inside browser frames. A website may block iframe embedding; in that case, use its visible external website link.

## Deploy
Upload the folder contents to a static hosting provider. No build step or package installation is required.


## Mobile live previews
The projects section displays each live website inside a phone-shaped frame. Visitors can scroll and tap inside the frame when the external website allows iframe embedding. Some hosting platforms block embedding; the visible "View live website" links remain available as a fallback.
